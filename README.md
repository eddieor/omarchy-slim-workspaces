# Slim Workspaces

Omarchy bar widget: compact workspace dots instead of numbered pills.

Plugin id: `eddieor.workspaces`

## Install

```bash
omarchy plugin add https://github.com/eddieor/omarchy-slim-workspaces.git --enable
omarchy plugin enable eddieor.workspaces --section left
```

## Develop

```bash
omarchy plugin validate .
```
